Detection

7 detectors, one score

Each detector adds points to an IP's score. Score decays linearly over the observation window — no false bans from old traffic.

🔍

Probe

Requests to sensitive paths: /.env, /.git/config, /wp-config.php, /phpinfo.php, admin panels, backup files and 30+ others.

+25 per request
⚡

Rate anomaly

More than 100 requests per 60 seconds from a single IP. Catches DDoS probes, aggressive scanners and credential stuffing bursts.

+25
🤖

Suspicious User-Agent

Matches known scanner UAs (Nuclei, sqlmap, Nikto, Nessus…), grabbers (Scrapy, HTTrack…) and generic automation clients.

+15 to +40
🔐

Bruteforce

More than 60% of responses are 404 with at least 10 requests total. Typical pattern of path-enumeration and credential bruteforce tools.

+30
📄

Sequential crawler

Five or more sequentially numbered URLs in a row — /page/1, /page/2… Characteristic of automated content scrapers.

+20
🖼️

No-asset bot

Loads pages but never requests CSS, JS or images — less than 10% of requests go to static assets. Real browsers always load assets.

+20
💣

URL overflow / WAF bypass

URLs longer than 2048 characters or containing WAF bypass keywords: bypass, shell, cmd, eval, exec.

+30
Installation

One command to install

Download the package for your distro from Releases. The package installs the binary, systemd unit, Fail2Ban filter/jail, logrotate config, and creates the nginx-sentinel system user.

From source
# amd64
sudo apt install ./nginx-sentinel_<version>_linux_amd64.deb

# arm64
sudo apt install ./nginx-sentinel_<version>_linux_arm64.deb

# Edit config and start
sudo nano /etc/nginx-sentinel/config.yaml
sudo systemctl enable --now nginx-sentinel
# amd64
sudo dnf install ./nginx-sentinel_<version>_linux_amd64.rpm

# arm64
sudo dnf install ./nginx-sentinel_<version>_linux_arm64.rpm

sudo pacman -U nginx-sentinel_<version>_linux_amd64.pkg.tar.zst

# Edit config and start

# Requires Go 1.19+
git clone https://github.com/mr-addams/nginx-sentinel
cd nginx-sentinel
sudo ./scripts/install.sh
sudo systemctl enable --now nginx-sentinel
After installation: edit /etc/nginx-sentinel/config.yaml — set general.log_file to your nginx access.log path, adjust scoring thresholds if needed, then start the service. Config reloads on SIGHUP without restart.
Whitelist

Legitimate traffic is never banned

Two independent mechanisms protect your real visitors and tools from false positives.

🔬

Automatic bot verification

Googlebot, Bingbot, Yandex, DuckDuckBot, GPTBot and 6 others are verified via reverse + forward DNS. Legitimate crawlers are never scored. Fakes get a penalty instead.

✅

Custom exclusions

Add your office IPs, VPN subnets (CIDR), monitoring services or SEO tools by User-Agent substring. Changes apply instantly on SIGHUP — no restart needed.

🔄

Live reload

All config changes — whitelist, detector scores, thresholds — reload with systemctl kill -s HUP nginx-sentinel. IP state and DNS cache are preserved.
